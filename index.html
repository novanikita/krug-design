Как выглядит и ведёт себя Круг

Одна страница — и инструкция, и живой пример. Цвета здесь берутся из того же файла, что и в приложении, а под каждым компонентом лежит его настоящий код. Если на этой странице что-то не так, значит, в приложении тоже.

Круг — дневник еды, в котором запись занимает секунды: одна строка «название количество», одна подсказка, Enter. Всё остальное на экране подчинено этой строке. Дизайн-система описывает, из чего она и окружение собраны, и какие правила нельзя нарушать, чтобы приложение оставалось быстрым и ощущалось родным на iPhone.

Четыре критерия

Из goal.md: быстрота использования, эстетическое удовольствие, простота поиска, надёжность без интернета. Любое решение проверяется этими четырьмя.

Правила, которые уже приняты

Запись — плоский список. Никаких завтраков и обедов: это лишний тап в самом частом сценарии. Время записи хранится, но не показывается.
Одна подсказка, не список. Строка ввода дописывает набранное серым, как адресная строка браузера. Список совпадений появляется только по просьбе: тап по серому тексту или свайп вниз по строке.
Строка читается как предложение. «Творог 5% 150 грамм», единицы полными словами с согласованием, число справа — табличными цифрами.
Никаких приблизительных КБЖУ. Если у продукта нет данных — справочный «средний» продукт того же типа, а не догадка.
Системные элементы — системные. Поле ввода, клавиатура, листы действий, меню по долгому нажатию, навигация — родные iOS, без копий. Своё рисуем только там, где у системы этого нет: кольца, пилюля, подсказка.
Иерархия — цветом, не весом. Второстепенный текст отличается оттенком (textSecondary, textTertiary), как в самом iOS, а не более тонким начертанием.

Цвет

Две темы, одни имена. Тёмная — не инверсия светлой, а своя палитра по образцу iOS: почти чёрный фон, поверхности #1C1C1E, притушенный второстепенный текст, оттенки макросов чуть светлее, чтобы читались на чёрном. Переключите тему кнопкой в шапке — вся страница перекрасится теми же токенами.

Дорожка кольца — его же цвет, приглушённый. Незаполненная часть кольца — это тот же оттенок с прозрачностью 20% в светлой теме и 28% в тёмной (Palette.track). Отдельного «серого» для дорожек нет: пустое кольцо читается как «то же кольцо, ещё не заполненное».
Четыре цвета — четыре величины. Зелёный всегда калории, красный — белки, оранжевый — жиры, синий — углеводы. В кольцах, буквах К/Б/Ж/У, числах записей, плитках и полях шторки — везде одно соответствие.
Заливка и чернила. У каждой величины два токена: заливка (kcal) для колец и бегунка и чернила (kcalInk) для той же величины, написанной текстом. В тёмной теме это один цвет; в светлой заливки слишком бледны для текста (зелёный на фоне — 2,4:1), и чернила темнее. Любой текст в приложении читается с контрастом не ниже 4,5:1 на любом фоне, серая подсказка — не ниже 3:1; это проверяет тест ContrastTests, и падает, если кто-то сделает цвет слабее.

            blue: CGFloat(hex & 0xFF) / 255,

Системное поле ввода, а за ним — серый текст подсказки ровно от того места, где кончается набранное. Подсказка одна и всегда целая: продукт и количество. Enter принимает её целиком.

Если догадка не продолжает набранное (опечатка, другой падеж, не та раскладка), она показывается целиком после стрелки: Enter никогда не запишет то, чего не видно.

Под строкой — только то, чего подсказка сказать не может: «Ищу…», «Ничего не найдено», «Нет сети», и всегда — ссылка на свой продукт. Камера и микрофон стоят в пустой строке и исчезают, когда есть текст; при правке записи их нет.

Код · UI/GhostField.swift
import SwiftUI

/// The input line with one inline "ghost" completion, the way a browser's
/// address bar guesses the rest: `suggestion` is the whole line the app
/// expects ("Творог 5% 150 грамм"), and whatever of it lies past the typed
/// text is drawn grayed-out behind the real, system text field. Enter
/// (the Go key) is how the guess is taken.
struct GhostField: View {
    @Binding var text: String
    var suggestion: String?
    var focus: FocusState<Bool>.Binding
    /// Called with the line as submitted (the field's text may not have
    /// caught up within the same update).
    var onSubmit: (String) -> Void
    /// A tap on the grey text — "not this one?" — opens the other matches.
    var onGhostTap: (() -> Void)? = nil

    /// Where the typed text ends on its first line, in the field's
    /// coordinates: a tap to the right of it (or below the first line) is on
    /// the ghost, a tap on the typed text itself just moves the caret.
    @State private var typedWidth: CGFloat = 0
    @State private var lineHeight: CGFloat = 0

    /// What's drawn after the typed text: the rest of a continuation, or —
    /// for a guess that doesn't continue it (a typo, another case form, the
    /// other keyboard layout) — the whole line after an arrow, so Enter never
    /// logs a line the user didn't see.
    private var ghost: String? {
        guard let s = suggestion, !text.isEmpty else { return nil }
        if s.lowercased().hasPrefix(text.lowercased()) {
            return s.count > text.count ? String(s.dropFirst(text.count)) : nil
        }
        return "\(text.hasSuffix(" ") ? "" : " ")→ \(s)"
    }

    var body: some View {
        ZStack(alignment: .topLeading) {
            if let ghost {
                Text(ghostText(ghost))
                    .frame(maxWidth: .infinity, alignment: .leading)
                    .allowsHitTesting(false)
                    .accessibilityHidden(true)
                    .background {
                        // The typed text alone, unwrapped, to measure where it
                        // ends; never drawn.
                        Text(text)
                            .fixedSize()
                            .hidden()
                            .background(GeometryReader { g in
                                Color.clear.preference(key: TypedSizeKey.self, value: g.size)
                            })
                    }
                    .onPreferenceChange(TypedSizeKey.self) { size in
                        typedWidth = size.width
                        lineHeight = size.height
                    }
            }
            // Vertical axis: a long line wraps like the logged lines do. Its
            // Return key would insert a newline, so a newline means "submit".
            TextField("Введите продукт…", text: $text, axis: .vertical)
                .focused(focus)
                .accessibilityIdentifier("line")
                .submitLabel(.go)
                .autocorrectionDisabled()
                .foregroundStyle(Palette.text)
                .onChange(of: text) { _, new in
                    guard new.contains("\n") else { return }
                    let line = new.replacingOccurrences(of: "\n", with: "")
                    text = line
                    if line.trimmingCharacters(in: .whitespaces).isEmpty {
                        focus.wrappedValue = false
                    } else {
                        onSubmit(line)
                    }
                }
                .accessibilityHint(suggestion.map { L("Подсказка: \($0)") } ?? "")
            // Over the field, a tap target where the grey text is: to the
            // right of the typed text on its line, and anything below it.
            // The typed text itself stays the field's (caret, selection).
            if ghost != nil, let onGhostTap {
                GeometryReader { g in
                    // Typed text that wraps has no measurable end: no target.
                    if typedWidth < g.size.width {
                        Color.clear
                            .contentShape(Rectangle())
                            .frame(width: g.size.width - typedWidth, height: lineHeight)
                            .offset(x: typedWidth)
                            .onTapGesture(perform: onGhostTap)
                            .accessibilityElement()
                            .accessibilityLabel(L("Другие варианты"))
                            .accessibilityIdentifier("ghost")
                        if g.size.height > lineHeight {
                            Color.clear
                                .contentShape(Rectangle())
                                .frame(width: g.size.width, height: g.size.height - lineHeight)
                                .offset(y: lineHeight)
                                .onTapGesture(perform: onGhostTap)
                        }
                    }
                }
            }
        }
        .font(.title3)
    }

    private struct TypedSizeKey: PreferenceKey {
        static let defaultValue = CGSize.zero
        static func reduce(value: inout CGSize, nextValue: () -> CGSize) { value = nextValue() }
    }

    private func ghostText(_ ghost: String) -> AttributedString {
        var typed = AttributedString(text)
        typed.foregroundColor = .clear
        var rest = AttributedString(ghost)
        rest.foregroundColor = Palette.textTertiary
        return typed + rest
    }
}

Четыре вложенных кольца в форме капсулы, снаружи внутрь: калории, белки, жиры, углеводы. Заполняются по часовой от верхней середины. Переключите пилюлю — кольца доедут от прошлых значений; М показывает перебор: кольцо идёт на второй круг с тенью на кончике, чтобы было видно, насколько сверх цели.

Н и М — среднее по дням с записями за календарную неделю и месяц, и только до сегодняшнего дня: пропущенный день не тянет среднее к нулю, а план на завтра ещё не считается. Панель прячется, пока открыта клавиатура.

import SwiftUI

struct StadiumRing {
    /// eaten / target, not clamped: past 1 the ring goes round a second lap
    /// over itself, Apple-Fitness style, so an overshoot reads as "how much over".
    var progress: Double
    var color: Color
}

/// Nested progress tracks in a capsule shape, outer to inner — the diary's
/// pinned summary. Each ring fills clockwise from the top center; `content`
/// sits in the empty middle. Progress changes animate from the previous
/// values, so flipping Д/Н/М or adding an entry reads as the rings moving.
struct StadiumRings<Content: View>: View {
    var rings: [StadiumRing]
    var strokeWidth: CGFloat = 13
    var gap: CGFloat = 3
    @ViewBuilder var content: Content
    @Environment(\.colorScheme) private var scheme

    var body: some View {
        ZStack {
            ZStack {
                ForEach(rings.indices, id: \.self) { i in
                    let ring = rings[i]
                    let inset = strokeWidth / 2 + CGFloat(i) * (strokeWidth + gap)
                    let p = max(0, ring.progress)
                    let style = StrokeStyle(lineWidth: strokeWidth, lineCap: .round)
                    let shape = StadiumShape(inset: inset)
                    ZStack {
                        shape.stroke(Palette.track(ring.color, dark: scheme == .dark), style: style)
                        shape.trim(from: 0, to: min(p, 1)).stroke(ring.color, style: style)
                        // Second lap over the full ring. The lap's end would
                        // vanish against the same colour underneath, so a
                        // short blurred dark stretch of the path sits just
                        // ahead of its tip — only there, never along the
                        // ring. Both are always present and trimmed, so they
                        // sweep along the path as the value animates.
                        let over = min(max(p - 1, 0), 0.999)
                        shape.trim(from: over, to: min(over + 0.012, 1))
                            .stroke(.black.opacity(p > 1 ? 0.45 : 0), style: style)
                            .blur(radius: strokeWidth * 0.3)
                        shape.trim(from: 0, to: over).stroke(ring.color, style: style)
                    }
                    .animation(.easeOut(duration: 0.65), value: p)
                }
            }
            content
                .padding(CGFloat(rings.count) * (strokeWidth + gap) + 4)
        }
    }
}

/// A capsule path that starts at the top center and runs clockwise — the
/// same origin and direction as a clock-face ring.
struct StadiumShape: Shape {
    var inset: CGFloat

    func path(in bounds: CGRect) -> Path {
        let r = bounds.insetBy(dx: inset, dy: inset)
        guard r.width > 0, r.height > 0 else { return Path() }
        let radius = min(r.width, r.height) / 2
        var p = Path()
        p.move(to: CGPoint(x: r.midX, y: r.minY))
        p.addLine(to: CGPoint(x: r.maxX - radius, y: r.minY))
        p.addArc(center: CGPoint(x: r.maxX - radius, y: r.midY), radius: radius, startAngle: .degrees(-90), endAngle: .degrees(90), clockwise: false)
        p.addLine(to: CGPoint(x: r.minX + radius, y: r.maxY))
        p.addArc(center: CGPoint(x: r.minX + radius, y: r.midY), radius: radius, startAngle: .degrees(90), endAngle: .degrees(270), clockwise: false)
        p.addLine(to: CGPoint(x: r.midX, y: r.minY))
        return p
    }
}

import SwiftUI

/// Nested circular progress rings, outer to inner, Apple-Fitness style —
/// the statistics screen's picture of a period. Each fills clockwise from
/// the top; a ring past its target stays full (the diary's stadium rings
/// show the overshoot, here the numbers do).
struct ActivityRings<Content: View>: View {
    var rings: [StadiumRing]
    var strokeWidth: CGFloat = 8
    var gap: CGFloat = 3
    @ViewBuilder var content: Content
    @Environment(\.colorScheme) private var scheme

    init(rings: [StadiumRing], strokeWidth: CGFloat = 8, gap: CGFloat = 3, @ViewBuilder content: () -> Content = { EmptyView() }) {
        self.rings = rings
        self.strokeWidth = strokeWidth
        self.gap = gap
        self.content = content()
    }

    var body: some View {
        ZStack {
            ForEach(rings.indices, id: \.self) { i in
                let ring = rings[i]
                let inset = strokeWidth / 2 + CGFloat(i) * (strokeWidth + gap)
                let p = min(max(ring.progress, 0), 1)
                Circle()
                    .inset(by: inset)
                    .stroke(Palette.track(ring.color, dark: scheme == .dark), lineWidth: strokeWidth)
                Circle()
                    .inset(by: inset)
                    .trim(from: 0, to: p)
                    .stroke(ring.color, style: StrokeStyle(lineWidth: strokeWidth, lineCap: .round))
                    .rotationEffect(.degrees(-90))
                    .animation(.easeOut(duration: 0.7), value: p)
            }
            content
        }
        .aspectRatio(1, contentMode: .fit)
    }
}

import SwiftUI

/// What was just deleted, kept for a few seconds so "Вернуть" can put it
/// back. Several deletes in a row stack up; one tap restores them all —
/// nothing deleted while the bar is up is ever lost.
@MainActor
@Observable
final class PendingUndo<Item> {
    private(set) var items: [Item] = []
    private var expiry: Task<Void, Never>?

    static var window: Duration { .seconds(4) }

    func add(_ item: Item) {
        withAnimation { items.append(item) }
        expiry?.cancel()
        expiry = Task { [weak self] in
            try? await Task.sleep(for: Self.window)
            guard !Task.isCancelled else { return }
            withAnimation { self?.items = [] }
        }
    }

    /// Everything pending, most recent last; the bar goes down.
    func take() -> [Item] {
        expiry?.cancel()
        let all = items
        withAnimation { items = [] }
        return all
    }
}

/// "Удалено — Вернуть" at the bottom of a screen while something can still
/// be brought back.
struct UndoBar: View {
    var shown: Bool
    var restore: () -> Void

    var body: some View {
        if shown {
            HStack {
                Text("Удалено").foregroundStyle(Palette.text)
                Spacer()
                Button("Вернуть", action: restore)
                    .fontWeight(.semibold)
                    .foregroundStyle(Palette.accent)
            }
            .padding(.horizontal, 20)
            .padding(.vertical, 14)
            .background(.regularMaterial, in: Capsule())
            .padding(.horizontal, 16)
            .padding(.bottom, 8)
            .transition(.move(edge: .bottom).combined(with: .opacity))
        }
    }
}

/// A form row with a number at the right, saved when editing ends — or
/// when the screen goes away mid-edit. Text that isn't a number leaves the
/// stored value alone, and the row shows it again.
private struct NumberRow: View {
    let label: String
    let stored: String
    let unit: String
    let decimal: Bool
    let color: Color
    let save: (String) -> Void
    @State private var text = ""
    @FocusState private var focused: Bool

    var body: some View {
        HStack {
            Text(label).foregroundStyle(color)
            Spacer()
            TextField("—", text: $text)
                .accessibilityIdentifier("field.\(label)")
                .keyboardType(decimal ? .decimalPad : .numberPad)
                .multilineTextAlignment(.trailing)
                .frame(width: 90)
                .focused($focused)
                .onAppear { text = stored }
                .onChange(of: stored) { if !focused { text = stored } }
                .onChange(of: focused) { if !focused { commit() } }
                .onDisappear { if focused { commit() } }
            Text(unit).foregroundStyle(Palette.textSecondary)
        }
    }

    private func commit() {
        save(text)
        // Whatever was stored after the save (the new number, or the old
        // one when the text wasn't a number) is what the row shows.
        DispatchQueue.main.async { text = stored }
    }
}

Как править

Источник правды — код приложения в apps/ios/Krug. Эта страница собирается из него скриптом, поэтому менять нужно код, а не страницу:

  1. Цвета — UI/Palette.swift: пара hex для светлой и тёмной темы на каждый токен.
  2. Шрифт — только системные стили (.title3, .body…); размеры в пунктах не задаются.
  3. Компоненты — файлы в UI/; код под компонентами на этой странице берётся из них при сборке.
  4. Текст страницы — design-system/src/index.template.html; стили — style.css.

Пересобрать: python3 design-system/tools/build.py. Хук перед коммитом не пропустит устаревшую страницу. Опубликованная версия обновляется при каждом пуше в main.
